# 등장인물 이미지 에셋

캐릭터별 영문 ID로 하위 폴더를 생성합니다.

예시: `assets/characters/seoyoon/normal.webp`, `smile.webp`, `surprised.webp`, `sad.webp`

- 동일 캐릭터는 얼굴·헤어스타일·복장 등 일관성을 유지합니다.
- 게임 이벤트 데이터에서는 캐릭터 ID와 표정 키로 이미지를 참조합니다.
- 표정 이미지가 없으면 기본 이미지(`normal.webp`)를 사용하도록 구현할 예정입니다.
- 이미지 파일을 실제로 추가하기 전에는 기존 대화 화면을 유지합니다.

현재는 캐릭터 이미지 파일이 등록되지 않았습니다.
