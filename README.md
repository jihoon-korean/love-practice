# 사람연습 Love Practice — Alpha 1.1

고품질 이미지 기반 장소 선택형 연애·생활 시뮬레이션.

## 실행
https://jihoon-korean.github.io/love-practice/

## 기능
- 주인공 이름 설정: 최대 4글자, 자동 저장
- 장소 8개: 집, 스타벅스, 애견샵, CU, 꽃집, 국밥집, 공원, 버스정류장
- 각 장소 클릭 시 이벤트, 구매, 휴식, 호감도 및 시간 변화
- 기존 Alpha 0.8/0.9 저장 데이터를 처음 실행 시 일부 자동 승계
- 모바일 가로 화면 / PC

## 중요: 이미지 에셋 배포 대기
- 새 화면은 `assets/town-map.jpg` 파일을 자동으로 읽습니다.
- 해당 이미지가 없으면 이전 `assets/town-art.svg`를 임시 배경으로 표시합니다.
- 목표 이미지에서 만든 지도 파일을 `assets/town-map.jpg`로 업로드해야 시안 품질의 마을이 보입니다.
- 기존의 별도 이동형 `game.js`는 보존했지만 새 버전은 `game-map.js`를 사용합니다.
- 기존의 고품질 마을 시안에는 글자와 UI가 이미지에 포함되어 있어 실제 적용 시 중복되는 일부 라벨은 후속 이미지 교체에서 정리할 필요가 있습니다.
