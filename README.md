# Love Practice — 사람연습

독립적인 모바일 가로/PC 브라우저용 연애 어드벤처 게임 프로토타입.

## 테스트
GitHub Pages: https://jihoon-korean.github.io/love-practice/

- 이동: WASD / 방향키 / 왼쪽 가상 조이스틱 / 맵 터치
- 상호작용: E / 대화 버튼
- 확대 축소: +/- 및 핀치
- 데이터: 브라우저 로컬 저장

## 현재 범위
이 버전은 모바일에서 검은 화면이 발생하는 문제를 분리 검증하기 위한 **Alpha 0.8 임시 벡터 맵**입니다.
사용자가 요청한 고품질 도트 맵과 실사 여성 이미지 에셋은 아직 GitHub 배포본에 적용되지 않았습니다.
추후 고품질 그래픽 에셋을 정식으로 업로드해 교체해야 합니다.

다른 프로젝트와 독립된 저장소입니다.
