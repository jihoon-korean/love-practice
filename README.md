## 현재 범위
이 버전은 모바일에서 검은 화면이 발생하는 문제를 분리 검증하기 위한 **Alpha 1.0 SVG 기반 카페 거리 그래픽**입니다.
벚꽃 거리·카페·편의점은 세부 SVG 에셋으로 교체되었습니다. 다만 목표 이미지 수준의 정교한 픽셀아트 타일셋과 실사 한서윤 인물 사진은 아직 적용되지 않았습니다.
추후 고품질 그래픽 에셋을 정식으로 업로드해 교체해야 합니다.

다른 프로젝트와 독립된 저장소입니다.
